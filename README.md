# 世界历史九年级上册 · 时间轴学习网页

一个**纯框架**的历史时间轴应用：不含任何具体历史内容（内容由你自己添加/导入）。
用于理清世界古代史的时间线与不同文明/区域的先后关系。

- 前端：`HTML + CSS + JS`（单页，无需构建）
- 后端：`Python` 标准库 `http.server`（**零第三方依赖**）
- 端口：`0100`（即 `100`，浏览器打开 `http://127.0.0.1:100`）

---

## 一、目录结构

```
History_Learning/
├── server.py            # 后端：静态文件服务 + 数据读写接口（端口 0100）
├── static/
│   └── index.html       # 前端页面（全部功能内联在此文件）
├── data.json            # （运行后生成）服务器持久化数据
└── README.md
```

## 二、启动方法

```bash
cd History_Learning
python server.py
```

启动后会自动打开浏览器到 `http://127.0.0.1:100`。
若端口被占用，可临时改用其它端口：

```bash
# Windows PowerShell
$env:PORT="8000"; python server.py
```

> 需要 Python 3.x，无需安装任何包。按 `Ctrl+C` 停止服务。

### 局域网访问（其它设备）

默认监听 `0.0.0.0`（所有网卡），因此**同一局域网内的其它设备**也可以用
`http://<服务器IP>:100`（编辑）或 `http://<服务器IP>:8424`（只读）访问。
启动时控制台会打印本机可用的局域网地址（如 `http://192.168.x.x:100`）。

- 查看本机局域网 IP（Windows）：`ipconfig`
- 若其它设备访问不到，多为 **Windows 防火墙**拦了 Python 的入站，请在防火墙放行 Python（或 100 / 8424 端口）。
- 数据通过服务器 `data.json` 在端口间共享；只读端口(8424)只能查看/导出，不能改内容。

**公网 IPv6（只读端口）**：`8424` 用 IPv6 双栈监听，公网可用
`http://[公网IPv6]:8424/` 访问（只读，安全）；`100` 编辑端口保持 IPv4，不暴露公网。
前提是你的网络分配了公网 IPv6 地址（`ipconfig` 里能看见 `2001:…`/`240e:…` 等非 link-local 地址），并放行防火墙。若没有公网 IPv6，则无法公网访问。

## 三、数据如何保存？

- **自动同步到服务器**：你对内容的**每次修改会自动写入**项目下的 `data.json`（由 `server.py` 提供），无需手动操作。
- **浏览器自动保存**：同时写入浏览器 localStorage，刷新/关闭不丢。
- **启动自动恢复**：后端启动时若没有 `data.json` 会自动创建一个空骨架；浏览器首次打开若本地没有数据，会自动读取服务器上的 `data.json`。
- **兜底/迁移**：页面右上角「⚙ 数据」仍有 导出 JSON / 导入 JSON / 手动保存到服务器 / 从服务器加载，用于备份、分享、换设备。

> 前端默认**不构造、不预置任何历史事件**，保持“纯框架”。首次打开画面为空，请通过右侧「🏛 文明」面板手动添加，或使用下方 JSON 直接导入。

## 四、JSON 数据格式说明

整体为一个 JSON 对象，顶层字段：

```jsonc
{
  "version": 1,                              // 版本号（建议保留 1）
  "title": "世界历史 九年级上册 时间线",        // 顶部标题
  "globalOptions": {
    "layout": "scale",                       // 布局："scale"（等比）或 "relative"（相对最小间距）
    "pxPer100": 30,                          // 等比模式下每 100 年对应的像素宽度（越小越紧凑，越小箭头越短）
    "theme": "parchment",                    // "parchment" | "ocean" | "forest" | "mono" | "custom"
    "customColors": {                        // 仅在 theme="custom" 时生效
      "bg":"#f5efe0",            // 页面背景
      "timeBox":"#e8d9b8",       // 时间框底色
      "timeBorder":"#8a6d3b",    // 时间框边框（兼箭头色）
      "eventBox":"#fdf6e3",      // 事件框底色
      "eventBorder":"#a8863f",   // 事件框边框
      "detailBox":"#ffffff",     // 详细框底色
      "detailBorder":"#cfc4a8",  // 详细框边框
      "symPlace":"#cfe8ff",      // 地点 【】高亮
      "symPerson":"#ffe0c9",     // 人名 （）高亮
      "symDot":"#c0392b"         // 分点下划线颜色
    },
    "show": {                                // 元素显隐开关（true=显示）
      "timeText": true,        // 时间框中的时间文字（时间框本身必显示）
      "eventBox": true,        // 事件框整体
      "eventText": true,       // 事件框中的事件文字
      "detailBox": true,       // 详细信息框整体
      "detailSymbol": true,    // 详细框中的标志符号（【】 （） 下划线）
      "detailText": true       // 详细框中的文字
    }
  },
  "lanes": [
    {
      "id": "l1",                // 唯一标识，字符串
      "name": "古代埃及",          // 文明名称（显示在每横行左侧标签）
      "visible": true,           // false 表示整行隐藏（隐藏的行会补位，不留空白）
      "color": null,             // 可选：行标签颜色（如 "#9c3"），null 用默认
      "events": [
        {
          "id": "e1",                        // 唯一标识
          "timeText": "公元前3100年前后",      // 时间框里显示的文字（可为任意字符串）
          "startYear": -3100,                // 起始年份（数值，公元前用负数）
          "endYear": -3100,                  // 结束年份（数值；=起点即单点；时间段则为其右边界）
          "eventText": "埃及初步实现统一",     // 事件文字
          "details": [                       // 详细信息，数组，每个元素一行字符串
            "【尼罗河流域】（那尔迈）_中央集权_、_文字_"
          ]
        }
      ]
    }
  ]
}
```

### 时间 (timeText / startYear / endYear)

- 两种表示方式：`XX世纪` 与 `XXX年`，均支持**公元前 / 公元**。
- 定位用的是数值 `startYear` / `endYear`，**公元前一律用负数**：
  - 公元前 3100 年 → `-3100`
  - 公元前 21 世纪 → 起点 `-2099`（-21×100+1），终点 `-2000`
    （即年份 `-2099 ~ -2000` 对应“公元前二十一世纪”）
  - 公元 476 年 → `476`，公元 1 世纪 → `1 ~ 100`
- `timeText` 是**给人看**的原文（如“公元前3100年前后”），与数值分开存储，二者不必一致。
- 页面新增事件弹窗里有「↗ 从文字自动算出年份」按钮，可自动把“公元前N世纪 / N世纪 / 公元前N年 / N年”换算成数值填入。

### 详细信息标记（可任意组合在同一行）

| 格式 | 含义 | 示例 |
| --- | --- | --- |
| `【地点】` | 地点 | `【尼罗河流域】` |
| `（人名）` | 人名 | `（汉谟拉比）` |
| `_分点_、_分点_` | 分点记忆（若干下划线项，用顿号分隔）| `_中央集权_、_文字_、_多神_` |

- 三者可在同一行/同一条信息里任意组合，例如：
  `【两河流域】（汉谟拉比）_法典_、_集权_`
- “分点记忆”由**顿号 `、` 分隔的若干个下划线项**构成，每个下划线项用 `_内容_` 包裹（存储格式）；但在**编辑弹窗里用“逐条类型化”方式录入**（选类型+填内容），保存时自动套好上述标记，你无需手写符号。导入的组合式 JSON 会被自动拆分回逐条类型。

## 五、功能说明

### 1. 时间轴（横向 × 纵向）
- **横坐标 = 时间**：从左到右由古到今。
- **纵坐标 = 地理区域 / 文明**：每个横行一个文明；地域相近的可按时间先后排在**同一横行**（前后文明只要时间不重叠即可共行）。
- 事件框为圆角矩形；同一横行的事件之间用**箭头**连接（箭头始终显示）。

### 2. 两种整体对齐方式（工具栏下拉切换）
- **等比缩放 (scale)**：严格按年份比例尺，x 坐标与年份成正比；相邻矩形之间保证不重叠并有足够空隙容纳箭头。
- **相对排列 (relative)**：**所有文明共享一条横轴，按时间先后全局排布**——保证不同文明的事件之间也有明确的先后顺序（例如公元前1000 → 公元前502 → 公元前500），相邻时间框之间施加固定最小间距，尽可能紧凑。
- 「每百年像素」下拉可调整等比模式的疏密：**数值越小整体越紧凑、箭头越短**（默认 30，可进一步调小至 15）。

### 3. 元素隐藏 / 显示（「👁 显隐」）
- 时间框、箭头：**始终显示**。
- 可独立开关：时间文字 / 事件框 / 事件文字 / 详细信息框 / 详细框标志符号 / 详细框文字。
- 文明行（「🏛 文明」面板取消勾选）：整行隐藏，**下方行自动补位，不留空白**；再次勾选即恢复。

### 4. 配色（「🎨 配色」）
- 预设 4 套主题：羊皮纸、海洋蓝、自然绿、打印黑白。
- **自定义**：点“自定义…”可逐项调色（页面背景、时间框、事件框、各标记高亮等），实时生效。
- 也可通过导入 JSON 中的 `theme` + `customColors` 加载自定义配色。
- 行标签颜色可在「🏛 文明」面板为每行单独指定。

### 5. 信息的添加 / 导入导出（「⚙ 数据」）
- **GUI 添加（逐条）**：点「🏛 文明」→ 添加文明/事件；编辑弹窗里 **详细信息采用“选类型 + 填内容”逐条添加**（普通文字 / 地点【】/ 人名（）/ 分点记忆），分点记忆一个框可填多个用顿号分隔的要点，保存时自动套好标记。也支持时间文字、起止年份、事件文字。点「＋添加文明/横行」后会自动打开文明面板并高亮新行；新增的“空文明”行在画布上会显示一个可点击的占位卡片（点击即可直接添加第一个事件），不会像以前那样塌陷看不见。
- **JSON 导入**：粘贴 JSON（格式见上文）覆盖当前数据；组合式标记会被自动拆分为逐条类型。
- **导出**：复制或下载为 `.json`（迁移、分享、备份）。

### 6. 打印 / 导出 PDF（「🖨 打印PDF」）
- 点击后调用浏览器打印服务（Windows 11 下可用“另存为 PDF”或金山/微软打印），**所见即所得**——页面显示成什么样，打印出来即什么样。
- 若时间轴较宽，建议在打印预览里选择**横向纸张**，并可用预览中自带的缩放（“适合页面宽度”）调整到单页或分页效果。

### 7. 其它
- 数据自动保存到浏览器；标题可改；文明/事件可排序、删除。

## 六、排障

| 现象 | 处理 |
| --- | --- |
| 浏览器打不开 | 确认先运行 `python server.py`，地址为 `http://127.0.0.1:100`（含端口号） |
| 端口被占用 | 用 `$env:PORT="8000"; python server.py` 换端口，再访问新端口 |
| 「保存到服务器」失败 | 该功能依赖后端，请通过 `server.py` 访问页面（而非直接用文件双击打开 html） |
| 导入导出的 JSON 无法用 | 检查顶层是否含 `lanes` 数组；`globalOptions` / `show` / `customColors` 可省略，程序会自动补默认值 |
| 打印内容过宽被切页 | 打印预览中把纸张设为横向后，再选缩放“适合页面宽度” |
